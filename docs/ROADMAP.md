# Roadmap & Phases

Phase 1 — MVP (1-2 weeks)
- FastAPI skeleton + recommend endpoint
- Basic ML pipeline: TF-IDF content-based recommender
- Notebook migration into `ml/` scripts
- Simple Next.js homepage and movie detail

Phase 2 — Hybrid + Mood (2-3 weeks)
- Add collaborative filtering (SVD)
- Build hybrid ranking & tune weights
- Implement mood tagging rules and mood selector UI
- Add explanation layer for recommendations

Phase 3 — Semantic Search & Personas (2-3 weeks)
- Add sentence-transformer embeddings and vector search
- Persona generation via clustering
- Cold-start onboarding flow

Phase 4 — Production hardening (1-2 weeks)
- JWT auth, Postgres schema, migrations
- Metrics & analytics dashboard
- Deployment guides (Vercel + Render + Supabase)

Phase 5 — Polish (ongoing)
- UI animations, explainability UX, A/B experiments
- Resume & README polish
